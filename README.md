# 🎓 NPTEL Tracker

A full-stack web application designed to help students track NPTEL course performance, monitor assignment eligibility, and predict final certification outcomes.

---

## 📌 Overview

NPTEL Tracker helps students manage and evaluate their NPTEL course progress by storing course details, tracking assignment performance, and calculating predicted final scores.

The application provides an easy way to determine whether assignment marks are sufficient and predicts the final certificate category based on combined assignment and exam performance.

---

## ✨ Features

### 📚 Course Management
- Add and manage NPTEL courses
- Store course duration and related details
- View course information in an organized dashboard

### 📝 Assignment Eligibility Check
- Enter assignment marks
- Automatically determine whether assignment scores are sufficient for eligibility

### 📊 Final Score Prediction
The application allows students to:

- Enter final exam marks (out of 100)
- Automatically convert exam score into **75-weightage**
- Add assignment score (**25-weightage**)
- Generate final predicted score **out of 100**

### 🏆 Certificate Prediction
Based on the final calculated score, the system predicts certificate category such as:

- Not Eligible
- Successfully Completed
- Elite
- Elite + Silver
- Elite + Gold
